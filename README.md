# Swiggy UI Arena

Frontend-only Swiggy-inspired UI clone for the UI ARENA challenge.

## Run
Open `index.html` directly, or use VS Code Live Server. No npm/backend is required.

## Included
- Home page with 8 restaurants
- Restaurant page with 6 menu items
- Functional localStorage cart
- Search page with live filtering
- Sign-in side drawer
- Help/FAQ page
- Responsive mobile navigation
- Toast notifications and micro-interactions
